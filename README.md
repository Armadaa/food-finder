# Food-Map

Statischer Prototyp einer Karte mit Essensläden in Hürth und Köln. Die Seite ist eine Progressive Web App aus HTML, CSS und JavaScript (ohne Build-Schritt) und kann direkt im Browser laufen.

Alle Läden, Bewertungen, Öffnungszeiten und Texte sind **Beispieldaten**. Es sind keine echten Geschäfte.

Live: https://armadaa.github.io/food-finder/
